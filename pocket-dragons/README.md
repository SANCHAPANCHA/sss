# Keepers' Lair — коммьюнити-сайт Pocket Dragons

Сайт для коммьюнити [Pocket Dragons](https://pocketdragons.io/) ([@Pocket_Dragons_](https://x.com/Pocket_Dragons_)).

## Что есть

- **Регистрация по почте** — без паролей: на email приходит 6-значный код (10 минут, 5 попыток, повторная отправка через 60 с). Первый вход создаёт аккаунт, дальше пользователь выбирает ник, X-хэндл и «стихию дракона».
- **Чат** в реальном времени (WebSocket) с каналами `#general`, `#hatchery`, `#fan-art`, `#off-topic`, онлайн-счётчиком, историей и антиспамом. Гости читают, участники пишут.
- **Контент из X** — участник вставляет ссылку на свой пост, выбирает категорию (Art, Memes, Guides, Lore, Video), пост встраивается через официальный виджет X. Реакции 🔥, сортировка New/Top, фильтры, живое появление новых постов.
- **Hoard** — рейтинг активности (+10 за пост, +5 за каждый 🔥 от других, +1 за 5 сообщений в чате) и личная Keeper-карточка.
- **AMA-таймер** — обратный отсчёт до еженедельного AMA по пятницам.
- **Гайд для новичков**, **FAQ** (включая предупреждение о скамерах), живая статистика, 3D-яйцо на Three.js.
- **Модерация**: email-адреса из `ADMIN_EMAILS` могут удалять любые сообщения и посты.

## Запуск

Нужен Node.js 22.13+ (используется встроенный `node:sqlite`).

```bash
cd pocket-dragons
pnpm install
pnpm dev        # http://localhost:3000 — API, WebSocket и Vite на одном порту
pnpm test       # тесты API: вход, посты, чат
```

Без `SMTP_URL` код входа печатается в консоль сервера и показывается в окне входа (только в dev-режиме).

## Продакшен

```bash
cp .env.example .env   # заполнить SMTP_URL, MAIL_FROM, ADMIN_EMAILS
pnpm build
pnpm start
```

Сайту нужен постоянно работающий Node-сервер (WebSocket + файл SQLite), поэтому подходят VPS, Railway, Render, Fly.io с постоянным диском. Чисто статический или serverless-хостинг не подойдёт.

`SMTP_URL` работает с любым SMTP-провайдером (Resend, SendGrid, Mailgun, Postmark…), например `smtps://resend:API_KEY@smtp.resend.com:465`. Без него продакшен-сервер не отправит коды.

За HTTPS-прокси (nginx, Caddy) пробросьте заголовки `Host`/`X-Forwarded-*` и WebSocket-апгрейд для `/ws`.

## Настройка

- Время AMA, каналы чата, категории и стихии — `src/config.js` (время AMA сейчас стоит как пример, 17:00 UTC; поставьте реальное).
- Тексты гайда и FAQ — `index.html`.

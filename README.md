# BURGER LAB — 3D-меню по QR-коду

Мобильное меню для бургерной: процедурный 3D-бургер (Three.js), который «разбирается» на слои при прокрутке, искры от гриля, 3D-наклон карточек, корзина и оформление заказа.

## Запуск

```bash
pnpm install
pnpm dev      # разработка
pnpm build    # статическая сборка в dist/
```

`dist/` — обычная статика, её можно залить на любой хостинг (GitHub Pages, Netlify, Vercel, свой сервер).

## QR-коды для столов

Откройте `qr.html` на опубликованном сайте, укажите адрес меню и число столов, нажмите «Печать».
Каждый QR ведёт на `…/?table=N`, номер стола показывается в шапке и в заказе.

## Редактирование меню

Блюда, цены и категории — в `src/menu-data.js`.

> Бэкенда нет: после «Оформить заказ» гость видит сводку с номером стола и показывает её официанту.
